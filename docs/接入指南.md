# 接入指南（给使用者）

按你的系统选一份，照着四步做完就能用：

| 系统 | 文档 |
|---|---|
| **macOS** | [接入指南-Mac.md](./接入指南-Mac.md) |
| **Windows** | [接入指南-Windows.md](./接入指南-Windows.md) |

两份内容一致，只差路径写法、PATH 配置和临时目录：

| | macOS | Windows |
|---|---|---|
| 全局安装位置 | `/usr/local/lib/node_modules`（可能需改用户目录） | `%APPDATA%\npm\node_modules`（默认可写） |
| 查 node 路径 | `which node` | `(Get-Command node).Source` |
| 配置目录 | `~/.teaming-mcp/` | `C:\Users\你\.teaming-mcp\` |
| 定时任务临时目录 | `/tmp` | `%TEMP%` |
| JSON 里的路径 | 直接写 | 反斜杠要写两个 `\\` |

---

## 一句话版本

```bash
npm install -g teaming-mcp          # ① 装
teaming setup --code ABC12345       # ② 用接入码配好（管理员给你）
                                    # ③ 在豆包工作里加自定义连接器
teaming doctor                      # ④ 验证（3 项 SKIP 是正常的）
```

装完就能用——**不需要飞书开发者账号、不需要授权任何应用、不需要填模型 key。**

> **遇到问题先看对应平台的「常见问题」**。Mac 上最常见的是 `npm install -g`
> 权限不足，Windows 上最常见的是 PowerShell 执行策略挡住 `npm`。
