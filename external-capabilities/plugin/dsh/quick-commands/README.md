# 常用指令（quick-commands）

输入框左侧多一个「☆ 常用」按钮：把常说的话（提示词、命令、模板）存起来，点一下就插入输入框，或者直接发出去。

## 和「待发送」的区别

- 待发送：**按会话**的草稿队列，写的是「这件事还没发」
- 常用指令：**全局**的一份清单，写的是「这句话我经常发」

两个插件互不依赖，可以只装一个。

## 用法

1. 输入框左侧点「☆ 常用」→ 面板从输入框上方弹出
2. 点「新建」：填标题（可留空）+ 内容 → 保存
3. 列表里**点一行 = 插入输入框**（可继续编辑再回车）；行右侧小按钮：**发送 / 编辑 / 删除**
4. 顶部搜索框按标题或内容过滤

发送 = 把内容设进输入框并提交；agent 正在跑时它会照常排队，不会打断当前任务。

## 存储

全局一份：`<DSH_HOME>/storages/quick-commands/commands.json`。跨会话共享，不按会话拆分；删掉这个文件就是清空。

## 边界

- 面板位置按可用空间选边（上/下），高度按窗口收；窗口太矮时贴到视口内并滚动
- 内容上限 8000 字、最多 300 条（防止一个手滑塞满）
- 插入是普通文本编辑，可撤销；发送会把当前草稿替换成该条内容
- 只在本机，不跨设备同步

## 验证

```bash
node --test test/store.test.mjs
```

覆盖：读取空列表、新增（标题去空白）、更新、删除、空内容拒绝、未知 id 拒绝。
