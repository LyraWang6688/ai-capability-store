# @lyra_wang/dsh-terminal-context

**点一下「发送终端」，把右侧边栏终端当前可见的最后 20 行发给 AI，让它接着往下干。**

不用复制粘贴、不用复述报错——但**什么时候发，由你决定**。

## 它解决什么

在侧边栏终端里跑命令时，Agent 看不到你敲了什么、看到了什么报错、在哪个目录。过去只能把输出复制粘贴给它。

装上之后：**一个按钮**，点一下，它就看到那一屏。

## 怎么用

1. 打开 DSH 右侧边栏终端，跑你的命令
2. 需要 AI 接手时，点输入框左侧的 **`⇪ 发送终端`**
3. 它会收到：那一屏的最后 20 行 + 最后提示符行（目录 / 本地还是远端）+ 屏幕上如果像报错会点出来
4. 按钮旁会短暂显示「已发送 N 行」

**它不做任何后台动作**：不轮询、不抓屏、不自动上报、不注入上下文。你不点，它什么都不知道。

## 和 0.5.x 的区别

| | 0.5.x | 0.6.0 |
|---|---|---|
| 触发 | 开关打开后持续共享 + 自动报错/完成 | **只有你点按钮那一刻** |
| 上下文 | 每步自动注入紧凑状态 | 不注入 |
| 自动唤醒 | 报错/完成时叫醒 Agent | 不叫醒（点按钮才叫） |
| 成本 | 每条命令一次请求 | **每次点击一次请求** |
| 心智 | 像"开着摄像头" | 像"按一次快门" |

0.5.x 的自动报错/自动推进代码已经移除，不是隐藏开关——想回到那种体验需要装旧版本。

## 边界（重要）

- **只覆盖 DSH 右侧边栏终端**：iTerm / 系统 Terminal 里的内容它看不到
- **只读当前可见的一屏**：滚上去的历史拿不到；发送时按最后 20 行截取
- **不执行命令**：只读文本，不注入输入、不改终端
- **不落盘**：Host 侧只保留该会话最近一次发送的内容（内存），进程退出即消失
- ⚠️ 一旦点了发送，那 20 行会进入模型请求与本地会话日志（终端里可能有 token，点之前留意）

## 安装

```bash
dsh plugin --profile <profile> add @lyra_wang/dsh-terminal-context
```

前置：DSH 桌面端（要用到输入框左侧的插槽）。

## 安全设计

- 界面半边只声明 `inject: ['slots']` —— 确定存在的服务就声明；v0.1.0 那次事故是**声明了不存在的服务**导致入口 pending，0.5.1 又踩了**该声明却没声明**的坑，两头都记在这里
- Host 半边用 `ctx.get('agents')` 可选访问，拿不到时按钮会返回「当前会话的 Agent 不在线」，不影响插件加载
- 没有定时器、没有后台任务：插件闲置时零开销
