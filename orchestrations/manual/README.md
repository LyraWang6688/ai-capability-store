# manual —— 人说一句就做

这个模式**没有钟**。触发就是一句话，终点是人拿到结果。

```text
① 触发        人说一句（"做一篇公众号文章"）
②-④ 执行      agent 按顺序调几个资产
⑤ 产出        人拿到东西（草稿、HTML、文件）
```

它和 `scheduled-task` 的区别只有一件事：**谁开始**。

| | scheduled-task | manual |
|---|---|---|
| 谁开始 | 时钟 | 人 |
| 中途有人吗 | 没有 | 有（可以随时改主意）|
| 终点 | 结果落到某个系统 | 结果交到人手里 |

## 具体编排不必对齐编号

`wechat-article` 的 `steps` 是 4 段（写 / 排版 / 动图 / 上传），不对应上面的编号。
**编号描述的是这一类任务的骨架，不是每条编排必须有的格子。**
