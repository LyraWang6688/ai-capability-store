# platform-intel — 四平台 × 三层的平台信息采集

**它是一条确定性流水线，不是一个 Skill。**

抓四个平台（Codex / Claude / DSH / 豆包工作）的公开信息，按三层填成结构化报告：

```
① 产品层   它现有的产品有哪些功能
② API 层   它开放了哪些能力 —— 能不能开发它的插件、能不能让 agent 调用它
③ 生态层   它怎么建生态 —— 个人能不能上传、现在怎么收费
```

## 为什么在 procedures/ 而不是 skills/

因为**流程是确定的**：抓哪几个地址、填哪几个字段、什么情况算"未找到"——
这些都不需要模型权衡。页面里"个人可以上传"这句要靠读，那是**阅读理解**，
是流水线内部的一个解析步骤，不是"这件事需要判断"。

判据：如果做成 Skill，每次跑的字段可能都不一样，而且没法回归测试。
做成 Procedure，给定同一份页面快照，必须提取出同一份结果——这是能断言的。

**什么时候才会需要 Skill**：当你要的是"基于这些信息给建议"（在哪个平台做插件、
定价多少）——那是判断，那时才拆 `skills/platform-strategy/`。现在只搜集事实。

## 两个阶段

| 阶段 | 做什么 | 状态 |
|---|---|---|
| **1 采集** | 抓 `sources.yaml` 里的地址，存原文快照，记录可达性 | ✅ 本目录 `collect.py` |
| **2 提取** | 从原文里按 `schemas.yaml` 填字段 | ⏳ 下一步（需要模型 + 夹具） |

阶段 1 先跑通的价值：**它先回答"哪些源其实抓不到"**。源清单里现在有一半是空的
（标 `url: null`），采集器跑一遍就能把"没找到"和"抓取失败"分开——
这两者的处置完全不同。

## 用法

```bash
python3 collect.py                    # 抓全部源，报告输出到 stdout
python3 collect.py --out report.json  # 落文件
python3 collect.py --only codex       # 只跑一个平台
```

退出码：0 = 全部可达或已跳过；2 = 配置错误（schemas/sources 读不出来）。
**单个源失败不改变退出码**——它是预期内的事，记在报告里，不是进程失败。

## 报告长什么样

两段：**信源可达性** + **按矩阵汇总的覆盖情况**。

```json
{
  "sources": {
    "claude-plugins-publish": {"url": "…", "status": "ok", "bytes": 4210, "sha256": "…"},
    "codex-plugins-portal":   {"url": "…", "status": "ok", "bytes": 90311, "sha256": "…"}
  },
  "coverage": {
    "claude": {
      "ecosystem": [
        {"point": "个人能不能上传、走哪条路", "state": "ready", "from": ["claude-plugins-publish"]},
        {"point": "分成比例", "state": "blocked", "from": [],
         "blocked": "官方文档无相关机制"}
      ]
    }
  },
  "summary": {"ok": 17, "failed": 0, "no_source": 0, "points_ready": 33, "points_blocked": 13}
}
```

`state` 三值，含义必须分清：

| state | 含义 | 处置 |
|---|---|---|
| `ready` | 这个点引用的**全部**信源都抓到了 | 阶段 2 可以提取 |
| `source_unavailable` | 有信源，但至少一个抓不到 | 换手段或换源 |
| `blocked` | **还没有信源**，靠 `blocked:` 说明为什么 | 去补源，或改走实测 |

**一个点只有在它引用的全部信源都 ok 时才算 ready** —— 部分成功不算成功，
否则报告会安静地比现实乐观。

## 纪律

1. **夹具测试**：`test_collect.py` 用假的 fetcher 断言同样的输入产出同样的报告，
   不联网。阶段 2 落地时同样要用固定页面快照断言字段提取结果。
2. **原文快照留证**：抓到的内容存 sha256，报告里能追到"这条结论来自哪份快照"。
3. **不猜**：源清单里没有的，写 `no_source`；抓取失败的，写失败码。**不写"大概如此"。**

## 编排

它会被一条定时作业调用（每天一次，产出报告）。编排层不在这里，也不属于本目录的定义。
