## 收什么

桌面应用、系统设置、终端 TUI —— **只要接口由别人拥有、改动不通知我们，就算这里**。

反例：一个 `--help` 稳定、参数确定的命令行工具**不属于本域**，它是 `procedures/`。
分界线不是"有没有窗口"，是"接口稳不稳"。

## 为什么桌面比浏览器更容易静默失效

浏览器的驱动面相对统一（CDP / Playwright 有标准协议），桌面各有各的：
辅助功能授权被系统更新收回、窗口结构随版本变、坐标随分辨率漂移。
三者都不会报错，只会让操作"看起来做了但其实没做"。

所以本域的记录里 `blocked` 与本域同等重要 —— **知道哪条路已经死了，
比知道哪条路能走更省时间**。
