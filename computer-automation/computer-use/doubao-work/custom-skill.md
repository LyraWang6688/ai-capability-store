# 给豆包工作装「技能」（入口与三条来源）

> 环境：macOS / DoubaoWork.app 2.33.5 / 已登录账号
> 实测日期：2026-10-24
> 验证方式：CDP 读 DOM 取「插件 · 技能 · 伙伴」页面结构 + 「+」菜单项文本 + 分类计数；未做上传实测
> 结论：部分验证 —— 入口与三条来源已确认；「上传技能」的文件格式与生效链路未实测

## 权限前提

| 前提 | 说明 |
|---|---|
| 已登录 App 账号 | 技能列表与安装入口跟账号走 |
| 能打开「插件 · 技能 · 伙伴」 | 侧栏可见即可，无系统权限要求 |
| 上传技能可能受企业管理策略限制 | 菜单里同时有「前往企业管理后台」，说明存在管理员维度 |

## 工具清单

| 工具 | 类型 | 用来做什么 | 前置条件 |
|---|---|---|---|
| `Runtime.evaluate` | CDP 方法 | 点侧栏入口、点「+」、读菜单文本与分类计数 | 已接管 App，见 [cdp-takeover.md](./cdp-takeover.md) |
| 文本匹配 + `.click()` | JS 片段 | 定位没有 `aria-label` 的菜单项 | 元素已在 DOM 里 |
| 顶部筛选面板 | App 内 UI | 读插件 / 技能 / 连接器三类计数 | 已在插件页 |

## 可复现步骤

1. **打开技能入口**：DOM 里按文本精确匹配侧栏的「插件 · 技能 · 伙伴」并 `.click()`。
   *观察*：`location.href` 变成技能页路由。
2. **点右上「+」**。*观察*：出现菜单浮层。
3. **读菜单项文本**（不要靠截图认字）：

   ```js
   [...document.querySelectorAll('*')]
     .map(e => (e.innerText || '').trim())
     .filter(t => t && t.length < 20 && /新建|上传|连接器|管理后台/.test(t))
   ```

   *观察*：拿到四项 —— 与豆包对话新建技能 / 上传技能 / 新建自定义连接器 / 前往企业管理后台。
4. **读分类计数**：点顶部筛选图标，读面板里「插件 / 技能 / 连接器」后面的数字。
   *观察*：实测 14 / 179 / 16。
5. **想做上传实测**：点「上传技能」，看它接受什么文件、传完是否立即出现在列表。
   做完把本文末尾的"未验证"逐条改成结论。

## 踩坑实录

| 症状 | 原因 | 修法 |
|---|---|---|
| 以为技能只能对话创建 | 只读发布说明的措辞，没看菜单 | 以界面菜单实测为准，别拿介绍当能力清单 |
| 按文本找不到菜单项 | 元素是 `div` / `span`，没有 `aria-label` | 遍历所有元素按 `innerText` 精确匹配，取最后一个命中 |
| 计数取不到 | 数字藏在筛选面板里，需要先点开 | 先点筛选图标，再读面板文本 |

### 还没验证的（别当成已支持）

| 缺口 | 影响 |
|---|---|
| 上传技能的**文件格式**（压缩包？能吃 `SKILL.md` 吗？） | 不知道能不能直接吃通用格式 |
| 上传后的**生效链路** | 不能承诺"传完就能用" |
| 技能的**版本与更新**机制 | 不确定能否覆盖升级 |
| 与**对话新建**的技能是否同一种对象 | 不确定两者差异 |

## 何时别用

- **只是想复用一段提示词**：先在对话里说清楚，稳定了再考虑存成技能。
- **想让它调用外部服务**：那是连接器（MCP）的职责，见 [mcp-connector.md](./mcp-connector.md)。
- **要跨宿主复用同一套能力**：这个 App 的技能是账号内的，换宿主带不走。
