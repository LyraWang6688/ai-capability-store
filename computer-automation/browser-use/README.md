## 收什么

**一个界面一个文件夹。** 这里的"界面"指浏览器里加载的、由别人维护的页面 ——
我们没法给它加 API，只能像人一样操作。

## 每个界面文件夹必须有

| 内容 | 回答什么 |
|---|---|
| `README.md` | 入口在哪（域名 / 路径）、用谁的会话、上次验证日期、结论 |
| `<功能>.md` | 这个界面的一个具体操作：可复现步骤 + 踩坑实录 + 何时别用 |

## 和另外两个域的关系

- 操作**确定**的 → 写成脚本，住 `procedures/`，本域的 `driven_by` 指向它
- 操作**需要判断**的（页面改版了怎么办、弹窗不认识） → 写成 Skill，住 `skills/`
- 本域只回答"这个界面现在还能不能被操作、我们上次验证是什么时候"

**一个界面可以同时被两者驱动** —— 例如 DeepSeek 账单页：开票是确定性脚本，
但"页面改版后该点哪里"需要模型判断，那就是一个 Skill。两条记录各自在自己域里，
本域的两条 `driven_by` 分别指向它们。
