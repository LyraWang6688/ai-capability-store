## 每篇文档必答

| 问题 | 为什么必答 |
|---|---|
| 入口是什么 | MCP server / CLI / 直接 CDP —— 决定哪些宿主能用 |
| 用谁的浏览器会话 | 独立实例，还是复用操作者已登录的 Chrome —— 决定会不会碰到真实账号数据 |
| 怎么验证这一步真的生效 | 页面快照 / DOM 断言 / 截图；没有验证手段的步骤不算稳定 |
| 什么情况下别用 | 反例比正例更能防止误用 |
| 已知坑 | 版本、权限、选中页漂移、超时…… |
