# InvestDesk 研究：标的推荐与沉淀

用户要的不是「AI 凭印象报几个代码」，而是**有依据、能追溯、能沉淀**的候选清单。

## 三条铁律

1. **先查数据，再开口**：不许凭训练记忆列代码。代码可能已清盘、改名、或根本不是那个主题。
2. **说清楚依据**：每个标的必须有数据支撑的理由（跟踪指数、规模、费率、资金流），不能只说「受益于 AI」。
3. **落库才能复用**：推荐完必须结构化输出，能落进备选池就落，不能落就给用户一段可粘贴的格式。

## 第一步：定主题与筛选口径

先把用户的问题翻译成可执行的筛选条件：

| 用户说法 | 翻译成 |
|---|---|
| 「AI 算力」 | 跟踪指数含「算力 / 人工智能 / 通信设备」，或成分股以算力基建为主 |
| 「红利」 | 跟踪指数含「红利 / 高股息」，股息率权重型 |
| 「人口老龄化」 | 医药 / 养老 / 保险 / 消费（银发经济） |
| 「最近强势的板块」 | 先查板块涨跌榜，再按强势板块找对应 ETF |

**主题必须落成「跟踪指数」或「成分股特征」**，否则筛选无从下手。

## 第二步：选数据源（按问题类型）

| 问题 | 优先数据源 | 为什么 |
|---|---|---|
| ETF / 基金筛选 | **广发证券「ETF 研究」「基金研究」插件** | 免费、有榜单与跟踪指数 |
| 基金诊断 / 组合分析 | **盈米基金插件** | 免费、有诊断维度 |
| 个股基本面 / 上市公司信息 | **证券之星插件** | 免费、覆盖 A 股 |
| 深度数据（估值分位、财务、公告、宏观） | **Wind Alice 插件** | 权威，但消耗积分，**省着用** |
| 板块强弱 / 资金流 / 大盘位置 | 豆包自带「金融数据检索」 | 免费 |

**积分纪律**：Wind 每日免费额度有限。一个推荐问题最多调 3 次 Wind，其余走免费插件。

## 第三步：四道筛子

详细阈值见 [`references/screening-rules.md`](references/screening-rules.md)。摘要：

| 筛子 | ETF | 个股 |
|---|---|---|
| 1. 主题匹配 | 跟踪指数必须真的对口，不能只看名字 | 主营收入占比 > 30% 才算真受益 |
| 2. 流动性 | 日均成交额 > 5000 万 | 日均成交额 > 1 亿 |
| 3. 规模/质量 | 规模 > 5 亿（避免清盘风险） | 市值 > 100 亿、非 ST、上市 > 1 年 |
| 4. 成本 | 管理费 + 托管费 < 0.6% | — |

**额外一条**：如果用户已有持仓，先查是否重复（同一跟踪指数只留一只）。

## 第四步：输出格式（必须用这个结构）

```markdown
## 结论
一句话说清方向判断（例如「AI 算力目前更适合用宽基 ETF 承接，而不是细分主题」）。

## 候选标的
| 代码 | 名称 | 跟踪指数 | 规模 | 日均成交额 | 费率 | 入选理由 |
|---|---|---|---|---|---|---|

## 淘汰说明
哪些看起来相关但被筛掉的，为什么（避免用户重复问）。

## 风险与前提
- 数据时点（哪一天收盘）
- 该方向的已知风险（估值、拥挤度、政策）
- 不构成买入建议，只是候选池
```

## 第五步：沉淀（关键）

推荐完成后**必须**把候选标的写进飞书多维表格 **「王颖的财富管理」**
（wiki 节点 `TTonwTJEKirrpnk4cRDc14LpnGg`）。

### 写哪两张表

**① 备选池**（`tblbxWHTH4itgUvM`）——每个标的一行

| 字段 | 写什么 |
|---|---|
| `代码` | 6 位代码 |
| `名称` | 标的简称 |
| `资产类型` | 股票 / ETF / LOF / REIT / 场外基金 / 其他 |
| `提及次数` | 已有该标的则 +1，否则填 1 |
| `首次提及` | 已有则不动，否则填今天 |
| `最近提及` | 填今天 |
| `状态` | 新增填「观察中」 |
| `推荐理由` | 本次的理由；已有则追加到末尾 |
| `关联灵感` | 关联到下面那条灵感记录 |

**② 灵感记录**（`tbllCkvNprHrYodl`）——本次提问一行

| 字段 | 写什么 |
|---|---|
| `问题` | 用户原话 |
| `时间` | 现在 |
| `话题` | AI / 人口老龄化 / 红利 / 其他 |
| `助手回复` | 你的完整回答 |
| `推荐标的` | 关联到上面那些备选池记录 |

### 去重规则

写备选池前**先按 `代码` 查一遍**：
- 已存在 → 更新（提及次数 +1、最近提及、追加理由、关联新灵感），**不要新建重复行**
- 不存在 → 新建

### 如果写不进去

飞书能力不可用时，输出下面这段让用户手动粘贴：

```
【建议写入备选池】
代码 | 名称 | 类型 | 推荐理由
515880 | 通信ETF国泰 | ETF | 跟踪通信设备指数，规模 xx 亿，费率 0.5%
```

## 反例（不要这样做）

- ❌ 「AI 算力可以关注：中际旭创、新易盛、寒武纪」——没有依据、没查数据、没筛选
- ❌ 列 10 个标的让用户自己挑 —— 筛选是 AI 的活
- ❌ 用「受益于」「有望」这类空话当理由 —— 必须有可核验的数据
- ❌ 给出目标价、买入点 —— 只做候选池，不给交易指令
