# 视觉规范

参考用户的 Harness / Loop 图：白底、浅灰输入结果区、浅蓝模块容器、白色卡片；正文深灰，辅助说明中灰，蓝色表达核心区域，绿色表达完成。

用容器表达归属、排列表达并列、箭头表达顺序。固定模板不承担任意因果网络。圆角约 16px，外边距 24px，统一细线图标；标题与节点名称比说明醒目。默认 900px 双列，宽度低于 600px 使用单列。字体不因卡片变多而无限缩小，画布随内容增长。

流程图仅使用浅色，所有输出格式均固定浅色，不跟随系统变暗。分层图保留浅深色选项：PNG 默认浅色、可指定深色；HTML 随系统主题或明确指定主题。导出 PNG 不经过浏览器，不截取用户屏幕，不包含页面工具栏。
