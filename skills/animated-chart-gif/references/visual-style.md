# 视觉规范：清楚、轻量、以过程为中心

依据用户提供的 Agent Loop / Agent Harness 两张参考图提取；不是截图像素复刻。

## 基础样式

- 背景白色 `#ffffff`；正文深灰 `#24292f`；解释灰 `#70757a`。
- 分区浅蓝 `#eff5fd`、边框 `#b9d2f1`；中性色块 `#f5f6f7`。
- 蓝色 `#0866e8` 表示当前焦点与流动，绿色 `#00a63c` 表示完成，红色 `#c44242` 仅用于明确失败或异常。状态同时用文字说明，不能只依赖颜色。
- 系统无衬线中文字体；标题约 28、节点 24、说明 19，按画布同比例调整。核心名称加重，辅助说明降级。不要用过小字号塞满画布。
- 圆角卡片约 18，分区约 24，描边 1–2；无厚阴影、无装饰渐变。图标如需要，统一为简洁线性图标，不能混用 emoji 和多种图标风格。

## 布局与动效

容器表达归属，排列表示并列，箭头表达方向。先固定布局再推进过程，避免节点随每帧变化而跳位。阅读路径与连接线对齐；分支、回路有真实连线及文字解释。

当前节点用强调边框和浅底突出，已发生节点保持可见。用沿连线流动的点或短线表示传递；到达后停留，让读者读完说明。不要逐帧重打长段文字。

一段动画解释一个问题；复杂结构可保留全局、局部高亮。演示单一路径时清楚标注，其余分支不能被误解为不存在。不要为了整齐把并行关系画成串行。

HTML 根据视口调整；内置模板在窄屏保持最小 720px 图宽并支持横向滑动，避免全文缩成小字。复杂场景可改为分镜/局部视图，不声称任何固定大图都能在 390px 内完整且清晰显示。GIF 没有暂停控件，逐步说明应简短，最后至少停留约 1 秒后重播。文字密集的长过程优先动态 HTML。
