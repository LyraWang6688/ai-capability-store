# 持仓分析框架

## 1. 总览

| 指标 | 口径 | 注意 |
|---|---|---|
| 总市值 | Σ 持有数量 × 最新价格 | 缺数量的标的不计入，要单独说明 |
| 总成本 | Σ 持有数量 × 单位成本 | |
| 累计盈亏 | 市值 − 成本 | 不要和今日盈亏混 |
| 累计收益率 | 盈亏 ÷ 成本 | 成本为 0 时显示「—」 |
| 今日盈亏 | Σ 日盈亏 | 表里有公式字段，直接取 |
| 今日收益率 | 今日盈亏 ÷ 昨日市值 | |

## 2. 平台分布

按 `投资平台` 聚合：市值、占比、累计盈亏、今日盈亏。

**要看的问题**：
- 是否某个平台占比过高（> 60% 意味着平台风险）
- 平台之间的表现差异是否合理（例如场内 vs 场外）

## 3. 集中度

| 指标 | 警戒线 | 说明 |
|---|---|---|
| 前 5 大占比 | > 60% | 过度集中 |
| 最大单只占比 | > 20% | 单标的风险过高 |
| 单主题占比 | > 40% | 押注单一方向 |

## 4. 盈亏归因

- **贡献前三**：按日盈亏（今日）和累计盈亏（长期）分别排
- **拖累前三**：同上
- 关注「贡献占比」：例如「紫金矿业贡献了今日涨幅的 80%」→ 说明今天的收益靠一只票

## 5. 风险敞口

按 `资产种类` 聚合：个股 / ETF / LOF / REIT / 场外基金 / 银行理财。

再按投资主线归类（AI、人口老龄化、红利、其他），看押注是否集中在一条线上。

## 6. 异常项

| 异常 | 判定 | 处理 |
|---|---|---|
| 缺持有数量 | 数量为空或 0 | 市值按 0 计，必须提示 |
| 价格长期未更新 | 最新价格日期落后 > 5 个交易日 | 提示可能停牌或数据源问题 |
| 单只大幅亏损 | 累计收益率 < −30% | 列入值得复核（不问「要不要卖」） |
| 单只大幅盈利 | 累计收益率 > +50% | 提示集中度风险 |
| 数据口径冲突 | 同一标的在多张表出现 | 指出，建议以最新持仓表为准 |

## 时点纪律

- 场内：当日收盘价（15:00 后）
- 场外基金：T 日净值（当晚公布）
- QDII：T-1 或 T-2

**组合的「今日盈亏」天然混合了不同时点**，必须在输出里标注。
