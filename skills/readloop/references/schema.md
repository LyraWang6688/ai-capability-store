## 建表时的两个坑

1. **主字段**是创建表时第一个字段，一旦建好不能改类型，建表时就要定对。
2. 飞书 API 没有独立的「多行文本」类型，长文本用 `text` 即可（界面里显示为单行，不影响读写）。

字段名不要改。读写都按字段名进行，改名等于初始化失败。
