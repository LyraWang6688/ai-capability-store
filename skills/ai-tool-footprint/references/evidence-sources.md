# 证据来源与解释口径

证据强度针对具体说法判断，不按来源一概分强弱。内部保留来源、覆盖、口径和待核验项；公开文章选取必要证据。

| 来源 | 能支持什么 | 不直接证明什么 |
|---|---|---|
| 有效会话/用户消息 | 可见范围内发生过交互、活跃日期与交互量 | 工作时长、成果质量 |
| 经核验的前台事件 | 指定设备与窗口内的前台停留 | 专注或有效工作时长 |
| 浏览器 History | 目标域名的访问记录 | 成功登录、实际操作功能 |
| 保存凭据元数据 | 存在相关服务的凭据记录 | 本机登录成功；可能来自同步/导入 |
| App 文件/缓存/安装包 | 存在痕迹、文件变动与当前安装情况 | 使用次数、首次使用、持续高频使用 |
| 明确操作日志 | 日志所描述的具体事件 | 日志覆盖之外的完整使用史 |
| 支付成功记录 | 明确的一笔付款 | 后续月份持续扣款或深度使用 |
| 发票 | 开票项目、金额和日期 | 每月自动续费成功 |
| 续费/到期/退订通知 | 对应通知或申请 | 扣款成功、已经失效或退款到账 |
| 项目/作品/运行结果 | 在已核验范围内的成果 | 未验证的上线、业务效果或节省时长 |

## 实际来源与限制

- 会话库：`~/.codex`、`~/.dsh/sessions/` 等。先检查实际格式，按稳定 ID 去重，统计有用户交互的会话；区分自动运行。整个目录文件数不是会话数。默认读元数据。
- App 数据：`~/Library/Application Support/<App>`。缓存、更新、同步、资源包打包时间影响 mtime；仅作辅助，不以数量判断投入高低。
- Chrome：先查询各配置文件 History 的首末覆盖。按 URL 主机名匹配工具域名及其子域名，不对整条 URL 做子串匹配；未核对的宽泛关键词只能列候选。
- 邮件：网易邮箱大师的 `mail.db`/`content.db`。工具名与账单词共同命中后才保留必要字段；不展示无关正文。旧采集器可能在本地扫描正文以判定命中，不应扩展输出内容。
- **LocalId 偏移**：此前观察到 MailContent 与 MailMeta 不能可靠对齐；对当前库先验证关联。未解决时不拼接主题与正文日期。正文中的开票/到期/扣费时间各有不同语义，不统一视为付款或收件时间。只有月份则保留月份精度。
- Screen Time/knowledgeC：存在文件、文件大小或总行数不等于已获得时长。先核验事件类型、起止、设备、覆盖及重叠，抽样对照系统界面；不可解析时不出时长结论。可能涉及跨设备数据。
- Spotlight 的 DateAdded、LastUsedDate：辅助线索，不认定首次安装或弃用日期；缺值不代表没用过。
- App Cleaner 扫描：只说明扫描时点留下的 App/版本痕迹，不能推断之前没安装。当前 App 的 mtime 也不等于安装日。
- Safari、受保护目录：权限错误如实记录，不试图绕过系统权限；不能将文件存在当作内容已读取。
- Shell 历史：只计与目标工具有关的命令，不输出整条可能含密钥的命令；不能换算会话数或工作时长。
- Cookies、Top Sites、钥匙串：非默认来源，仅在主题确需账户相关痕迹时考虑必要元数据；不取值。存在 Cookie 不证明登录成功。
- 系统设置完成标记、备份配置：用于分析迁移、同步、恢复等可能性；不能独立证明机器最早使用日期或已经发生过迁移。

早于当前设备使用期的材料要辨别：历史账单可证明更早的个人经历，不能证明当时在本机使用；资源包旧时间戳不能证明更早使用。未找到邮件收据不等于没付费，其他支付渠道及设备可能不在覆盖内。

## 数据库快照

SQLite 优先从只读连接用 backup API 生成一致性临时快照后查询，保证包含 WAL 中已提交数据；禁止只复制主文件后忽略 WAL。快照失败或超时则记录失败，不返回空集合冒充无记录。及时清理临时敏感文件。

## 旧脚本输出的兼容边界

`collect_evidence.py` 的 `files` 是按文件 mtime 的数量，`browser` 是 Chrome Default 按月访问统计；`install` 是安装/扫描/更新线索；`billing` 是待核验账单类线索，`paid_visit` 仅为相关页面访问。它没有实付金额统计，也不维护增量状态。宽泛域名匹配和旧库解析结果须复核后进入正式底稿。

旧 JSON 中 `paid` 可能混有提醒、到期等日期，默认按待核验账单线索处理。新绘图字段 `confirmed_paid` 只接收人工或规则核验的付款月份；单靠旧脚本不能填充该字段。

累计底稿和进度格式见 [collection-state.md](collection-state.md)。不要用月度聚合覆盖原始事件和来源状态；未完成来源不推进检查点。
